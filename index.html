Teacher Mode

lesson ID・英文・日本語訳を入力すると、GitHubにアップロードするための lessons.js を生成できます。

教師用
基本運用
  1. lesson ID と問題を入力する
  2. 「lessons.jsを生成・ダウンロード」を押す
  3. GitHub上の lessons.js を上書きする
  4. 固定入口URL、または ?lesson=ID 付きURLを配布する
入力形式

1行につき1問です。最大10問まで読み込みます。
英文 || 日本語訳

英文に「/」を入れるとチャンク単位、入れない場合は単語単位になります。

単語単位：I was shocked by the tragic sight. || 私はその悲惨な光景に衝撃を受けました。
チャンク単位：I was shocked / by the tragic sight. || 私はその悲惨な光景に衝撃を受けました。

生徒用URL

GitHubに lessons.js をアップロード後、このURLを生徒に配布できます。

既存の lessons.js に追加する場合

過去のレッスンを残したい場合は、下のコードを window.LESSONS = { ... } の中に追加してください。
